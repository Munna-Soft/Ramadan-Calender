# 🌙 রমজান ক্যালেন্ডার ২০২৬ - সেহরি, ইফতার ও নামাজের সময়সূচি

### 📅 একটি সম্পূর্ণ ওপেন সোর্স, আধুনিক ও ব্যবহারকারী-বান্ধব রমজান ক্যালেন্ডার ওয়েব অ্যাপ্লিকেশন

এই প্রজেক্টটি **পূর্ণ বৈশিষ্ট্যসম্পন্ন রমজান ক্যালেন্ডার** যা বাংলাদেশের ৮টি প্রধান বিভাগের জন্য সেহরি, ইফতার ও নামাজের সঠিক সময় প্রদর্শন করে। এটি বিশেষভাবে ডিজাইন করা হয়েছে যাতে ব্যবহারকারীরা তাদের অবস্থান অনুযায়ী সময় দেখতে পারেন এবং কাউন্টডাউন টাইমার দেখতে পারেন।
